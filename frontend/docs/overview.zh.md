# 概述

md-builder 是一个面向科学计算软件的测试平台:每次代码推送时,它会在一组
远程环境中运行你的构建与测试命令,并以通过/失败矩阵的形式展示结果(每行
一个提交,每列一个测试环境)。

工作流程简述:

1. **配置站点**(Settings):填写代码仓库、测试输入仓库以及用于测试的
   ref —— 私有仓库还可选配置凭据。
2. **注册环境**(User center):填写将要运行测试的远程主机,并为其打上
   标签。
3. **添加测试矩阵**(代码仓库根目录的 md-builder.yaml):声明哪些标签
   运行哪些命令。
4. **推送代码**:GitLab webhook 为每个矩阵条目向匹配的环境派发一条任务图
   (clone → build → 测试);结果显示在仪表板上,且每个阶段的日志可以
   实时查看。
